\# The Core



> Игра на движке Godot Engine 4.5, действие которой происходит внутри полого шара



\## Описание



> Действие игры происходит внутри полого шара. Этот проект является шаблоном игры с реализованными механиками ходьбы, бега и прыжков.



\## Управление



| Действие | Клавиша |

|----------|---------|

| Движение | W, A, S, D |

| Бег | Shift |

| Прыжок | Space |

| Осмотр | Мышь |
